# Etapa 1 — Viabilidade técnica das integrações

Data da verificação: 17/10/2026. **Importante:** o ambiente de desenvolvimento (sandbox) bloqueia `api.mercadolibre.com`, `api.telegram.org` e `graph.facebook.com` (erro 403 do proxy / sem DNS). Portanto **nenhuma chamada real a essas APIs foi executada** durante o desenvolvimento. O que está marcado "confirmado" veio de documentação/pesquisa; o que está "a validar" só poderá ser verificado no seu servidor com as suas credenciais (há botões de teste no painel e o comando `npm run smoke` descrito no README).

| Capacidade | Situação | Observações |
|---|---|---|
| Painel, banco, filas, workers, score, antispam, mensagens | **Pronto (testado localmente)** | Postgres e Redis reais nos testes. |
| Buscar ofertas do Mercado Livre pela API oficial | **Depende de credenciais — a validar** | A API pública de busca (`/sites/MLB/search`) historicamente era aberta, mas há relatos (fontes não oficiais) de HTTP 403 sem token desde 2025, e o 403 oficial também ocorre com app bloqueado/escopo insuficiente. O adaptador usa OAuth (app criado no DevCenter do ML) e trata 401/403/429. Se a busca continuar bloqueada para o seu app, o painel mostra "Autenticação necessária"/"Erro" com a causa, e a fonte `fixture` permite testar o fluxo. |
| Campos de preço original / promoção na API | **Parcial** | `original_price` costuma existir apenas em anúncios com promoção; não é garantia de desconto real. Por isso o sistema trata como **"anunciado"** e só exibe "De/Por" quando o preço de referência é **verificado** pelo histórico próprio (maior preço observado em 90 dias) — ou seja, o histórico precisa de alguns ciclos de coleta antes de gerar "De/Por". Até lá a mensagem mostra só o preço atual. |
| Cupom, parcelamento, ofertas relâmpago, "mais vendidos" | **Somente se a API devolver o dado** | O sistema nunca infere: sem dado, sem exibição. |
| Gerar link de afiliado por API | **NÃO suportado oficialmente** | Pesquisa não encontrou API pública de geração de links do programa de afiliados do ML; o gerador oficial é manual no portal de afiliados. Automatizar com cookies/sessão do portal seria fora de método autorizado — **não implementado**. Fluxo adotado: **fila de links pendentes + exportação CSV + importação em lote** (você gera no portal oficial e cola `URL_ML ; URL_AFILIADO`). Cada link importado é validado (host permitido, formato, destino resolvido = mesmo produto) antes de liberar a publicação. |
| WhatsApp: publicar em grupo existente "ACHADOS VIP" (grupo comum do app) | **NÃO suportado por API oficial** | A Cloud API convencional não envia para grupos comuns. |
| WhatsApp Business Platform — **Groups API** | **Suportado com restrições — a validar** | Segundo a documentação da Meta (via pesquisa): exige conta/número da WhatsApp Business Platform (hoje apontada como aberta a negócios com Official Business Account), grupos **criados via API**, **máx. 8 participantes**, até 10.000 grupos por número, entrada **só por link de convite**. Não serve para um grupo grande já existente nem para migrar seus membros automaticamente. Adaptador implementado (Modo A), desativado até configurar credenciais e um `group_id`. |
| Telegram (canal/grupo via Bot API) | **Suportado oficialmente** (a validar com seu bot) | Modo C. Limite prático ~20 msgs/min por grupo; legenda de foto 1024 caracteres (o formatador respeita). Observação: confirme que a divulgação de links de afiliado do ML no canal está de acordo com os termos do programa. |
| Webhook autorizado | Suportado | Envia JSON assinado (HMAC) para URL sua (ex.: n8n/Make). |
| Automação via WhatsApp Web não oficial (whatsapp-web.js/Baileys) | **Não implementada** | Viola os termos do WhatsApp, risco de banimento do número; fora do escopo exigido (sem "artifícios para ocultar automação"). |
| Métricas de cliques/vendas/comissões | **Não disponível** | Sem API autorizada; o painel mostra "indisponível" (nunca valores fictícios). Importação comprovada (CSV do portal) fica como evolução. |

## Conclusão prática para o grupo "ACHADOS VIP"
1. **Hoje, sem alterar nada:** Modo B (fila) — o sistema busca, classifica, valida links e entrega a mensagem pronta (texto + imagem) na aba "Fila manual", com botão "copiar" e "marcar como publicada".
2. **Automação total no WhatsApp:** só via Groups API em um grupo novo (≤ 8 membros por convite) — útil para equipe/teste, não para audiência grande.
3. **Automação total para audiência grande:** Modo C com **Telegram** (canal ilimitado de inscritos), mantendo o WhatsApp no Modo B.

Fontes consultadas: documentação Meta Groups API ([developers.facebook.com/documentation/business-messaging/whatsapp/groups](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/), resumida por terceiros), páginas de erro 403 do [DevCenter do Mercado Livre](https://developers.mercadolivre.com.br/erro-403), discussões de desenvolvedores sobre ausência de API de afiliados, e guias do [python-telegram-bot sobre limites](https://github.com/python-telegram-bot/python-telegram-bot/wiki/Avoiding-flood-limits).
